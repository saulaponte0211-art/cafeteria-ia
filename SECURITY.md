# Política de seguridad

Este repositorio es **intencionalmente vulnerable**: es material de un taller universitario de
seguridad con IA. Las vulnerabilidades están ahí a propósito, así que **no hace falta reportarlas**. 🙂

- No despliegues esta aplicación en un servidor accesible desde internet.
- Las «claves» y «contraseñas» del código y del historial de git son ficticias.
- Si encuentras un problema en las herramientas del taller (por ejemplo, en `desbloquear_arbitro.py`
  o en la configuración del Codespace) que afecte a quien lo usa, abre un *issue*.
